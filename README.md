# Roast & Co. Coffee

Static 5-page website (HTML, CSS, vanilla JS). No build step.

## Run locally
Open `index.html`, or run `npx serve .`

## Deploy
1. Push to GitHub (`git init`, `git add .`, `git commit`, `git push`).
2. Netlify: Add new project > Import an existing project > pick the repo.
3. Build command: leave empty. Publish directory: `.`
4. After the first deploy, open Netlify > Forms to see contact messages
   (Project configuration > Notifications > Form submission to get them by email).

## Before going live
- Replace the placeholder email `hello@roastandco.example` and phone `+92 300 0000000`.
- Photos are loaded from Unsplash; swap in your own for production.
